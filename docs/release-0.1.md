KRIECHSTROM for VIBE FM 0.1, the first release: KRIECHSTROM 0.5.1 for the M-VAVE FM-1 as a native Vibe, built with the
VIBE FM SDK.

- the FM-1 firmware's sound engine and edit logic, bit for bit at 44.1 kHz, resampled at other rates
- pages for SOUND, ENV, LFO, ARP, FX and SEQ on the 480 x 320 display, a drum grid and a piano roll, the mixer, the
  project slots
- the display wears with the master: the creep figure, tears on the hits, split colours, spliced bands, grain
- the pads: mutes, DICE, hold effects, drum lanes with velocity, the 16 steps on the SEQ page
- the audio input through the mix and the master: DRIVE, sends, a GATE by a track, INFECT's source
- MIDI OUT per track with clock, CV and GATE from one track
- the stage (960 x 540): the four patterns, the creep over the scope, the master's chain
- DAW parameters and transport; the session, four project slots and user sounds stored

Files: `kriechstrom.wasm` (the Playground: drop it onto the device), `kriechstrom.zip` (VIBE FM VST: drop it onto its
window). The source is this tag; `git clone --recursive` brings KRIECHSTROM's core with it.
