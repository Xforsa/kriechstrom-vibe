KRIECHSTROM for VIBE FM 0.3.

- a demo song to start from: four project slots in E minor at 100 BPM (THEME, DRIVE, BREAK, WEIGHT, on ROOM, ROT, GATE
  and SLAB KIT) and a SONG over them. The first start plays its theme on PLAY; SEQ > SONG and F5 play the whole song;
  MENU > PROJECT and SHIFT + ENTER bring it back into the empty slots

Files: `kriechstrom.wasm` (the Playground: drop it onto the device), `kriechstrom.zip` (VIBE FM VST: drop it onto its
window). The source is this tag; `git clone --recursive` brings KRIECHSTROM's core with it.
