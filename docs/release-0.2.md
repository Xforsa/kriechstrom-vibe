KRIECHSTROM for VIBE FM 0.2.

- SONG, AUTOMATION and FM6's operator pages; MY SOUNDS, 32 user sounds to save and load
- the creep drawn as a discharge (jagged, fine filaments); the power-on picture shows the name only
- SAMPLE and SLICE sounds, which play recorded sound this firmware does not carry, are left out of the sound list
- the site: https://xforsa.github.io/kriechstrom-vibe/

Files: `kriechstrom.wasm` (the Playground: drop it onto the device), `kriechstrom.zip` (VIBE FM VST: drop it onto its
window). The source is this tag; `git clone --recursive` brings KRIECHSTROM's core with it.
