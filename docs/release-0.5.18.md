KRIECHSTROM for VIBE FM 0.5.18, on KRIECHSTROM 0.5.2 for the FM-1.

- SPINE now moves the followers' steps, note for note, not only their keys (measured on each track's own output)
- on SPINE's page any keys move the followers: the device's, the computer's keyboard, MIDI
