KRIECHSTROM for VIBE FM 0.5.12, on KRIECHSTROM 0.5.2 for the FM-1.

- MENU > PAD FX: pads 9-16 hold effects, with SHIFT eight more, each chosen from eighteen
- thirteen pedals, each its own box, knobs and screen
- FM6's algorithm explained on its page
- MENU always opens on its tiles; DATA and ENTER are each page's own (no FOCUS taking them over)
- SHIFT + DATA changes the engine on every SOUND page; a tapped SHIFT holds for a knob's whole turn
- DICE gives a new part on every press
- nothing written over a picture any more

Files: `kriechstrom.wasm` (the Playground: Load your own .wasm, or drop it onto the device), `kriechstrom.zip`
(the VIBE FM plugin: drop it onto its window). The source is this tag; `git clone --recursive` brings KRIECHSTROM's core with it.
