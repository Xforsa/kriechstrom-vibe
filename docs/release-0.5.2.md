KRIECHSTROM for VIBE FM 0.5.2, on KRIECHSTROM 0.5.2 for the FM-1.

- MENU > MY PROJECTS: 32 whole projects (the music, slots A-D, the pedals, the sampler's recordings), named and kept;
  SHIFT + F5 exports one as a .kxp file
- MENU > PROJECT FILES: .kxp files imported from VIBE FM/kriechstrom/, or dropped on the plugin's window
- MENU > OUTPUTS: in a DAW with more outputs, T1-T4 on OUT 3-10, the effects on 11/12, the input on 13/14

Files: `kriechstrom.wasm` (the Playground: Load your own .wasm, or drop it onto the device), `kriechstrom.zip`
(VIBE FM VST: drop it onto its window). The source is this tag; `git clone --recursive` brings KRIECHSTROM's core with it.
