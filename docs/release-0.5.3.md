KRIECHSTROM for VIBE FM 0.5.3, on KRIECHSTROM 0.5.2 for the FM-1.

- the mouse in the plugin and the browser: click what is shown (tabs, tracks, steps, pedals, sounds, the master's
  tiles, slots, projects, the start screen); a drag in one of the four columns turns that column's knob
- HOME tells how each page's effect goes on and off; an effect that is off says so on its page, and what turns it on

Files: `kriechstrom.wasm` (the Playground: Load your own .wasm, or drop it onto the device), `kriechstrom.zip`
(VIBE FM VST: drop it onto its window). The source is this tag; `git clone --recursive` brings KRIECHSTROM's core with it.
